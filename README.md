# منصة العمر الاحترافية — v2

موقع ثابت (بدون سيرفر) بيشتغل على GitHub Pages. كل البيانات بتتحفظ على جهاز المستخدم فقط.

## الملفات
| ملف | وظيفته |
|---|---|
| `index.html` | الصفحة + SEO + سكربت صغير في الـ head بيحدد اللغة والثيم قبل أول رسم |
| `style.css` | التصميم والأنيميشن (كله transform/opacity وبيقف مع `prefers-reduced-motion`) |
| `i18n.js` | كل النصوص بالست لغات |
| `script.js` | المنطق: العداد الحي، الهجري، العيلة، الحفظ، التثبيت |
| `effects.js` | الكونفيتي وعدّاد الأرقام (بدون أي مكتبة خارجية) |
| `share-card.js` | رسم بطاقة الصورة (PNG 1080×1350) |
| `sw.js` + `manifest.webmanifest` | التطبيق يتثبّت ويشتغل بدون إنترنت |
| `fonts/` + `tools/download-fonts.py` | استضافة خط Cairo على موقعك |

## خطوات مرة واحدة
1. **الخط:** شغّل `python tools/download-fonts.py` (محتاج إنترنت مرة واحدة) وارفع `fonts/` و`index.html`. السكربت بيشيل روابط Google Fonts من الصفحة لوحده.
2. **SEO:** لما الرابط النهائي يتحدد، أضف في `<head>`: `<link rel="canonical">` و`og:url` و`og:image` (روابط كاملة)، وملف `sitemap.xml` وسطر `Sitemap:` في `robots.txt`.

## مع كل نشر (Deploy)
غيّر `VERSION` في أول `sw.js` (مثلاً `v2.0.1`) عشان المتصفحات تاخد الملفات الجديدة وتمسح الكاش القديم.
